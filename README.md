# PESTAL
Je veux créer une application qui est utile a toute la communauté 

## Application : Entraide communautaire

Une petite application en Python où chaque membre de la communauté peut
**proposer son aide** ou **demander de l'aide**.

### Lancer l'application
```
python entraide.py
```
Un menu s'affiche : tapez le chiffre de l'action voulue.
Les annonces sont enregistrées dans `annonces.json`.

### Lancer les tests
```
python -m unittest
```

Aucune installation nécessaire : seulement Python 3.
